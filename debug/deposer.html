Déposer des fichiers

Choisissez des fichiers sur le téléphone (photos, exports du cache…) : chacun est déposé dans le dossier choisi du dépôt privé, un commit par fichier. Un fichier déjà présent sous le même nom n'est pas renvoyé.

1 · Jeton GitHub

Une seule fois, dans Chrome (pas l'application GitHub) :

  1. ouvrez github.com › créer un jeton ;
  2. nom : « dépôt téléphone », expiration : 90 jours ;
  3. Repository access : Only select repositories › Ar_city-photos ;
  4. Permissions › Repository permissions › Contents : Read and write ;
  5. Generate token, copiez-le et collez-le ci-dessous.

Il ne donne accès qu'au dépôt choisi à sa création, et seulement à ses fichiers. « Oublier » l'efface de ce téléphone ; on peut aussi le supprimer sur GitHub.
