Export du cache

Enregistre dans des fichiers JSON (20 Mo au plus chacun) ce que l'application a mémorisé sur cet appareil, pour le rejouer dans les tests. Déposez ensuite les fichiers dans le dépôt privé Ar_city-photos (« Add files via upload »). Rien n'est envoyé ailleurs ; aucun réglage ni calque personnel n'est inclus.

Lecture du cache…

1 · Relief d'un lieu

Les tuiles de relief ne sont mémorisées que là où l'application a calculé le relief (carte ou photo rejouée). Choisissez un lieu connu, ou saisissez des coordonnées.

2 · Données mémorisées

Lieux, monuments, tours, pylônes, sommets lointains de toutes les zones visitées (sans la mémoire des bateaux et avions ni les empreintes de bâtiments).
