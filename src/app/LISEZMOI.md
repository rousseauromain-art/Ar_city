# app — racine de composition (étape 9b)
- `application.js` : le SEUL endroit qui assemble réseau, caches, sources de données (`donnees/`), relief (`scene/terrain.js`, Worker du masque) et décide quand charger : lieux, sommets lointains, relief en deux passes avec repli AWS, monuments + tours/bâtiments hauts/statues OSM, pylônes, repères hauts. Mêmes seuils de déplacement que la v1, recul progressif en cas d'échec. En mode direct, le trafic : avions toutes les 20 s (60 s sans relais), bateaux toutes les 30 s, mémoire de l'appareil dès le premier point GPS, rattrapage toutes les 3 s pendant 1 min après un saut de plus de 3 km. Expose `donnees()` (pour `moteur/scene.js`), `definirPosition`, `recharger`, `etat()` (diagnostic).
- Aucun module de `donnees/` n'en connaît un autre ; aucun calque n'importe `app/`.
