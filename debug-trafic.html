Débug trafic — avions, bateaux, pylônes

Page à part de « villes à l'horizon » : envoie exactement les mêmes requêtes que l'appli (mêmes formules de zone), et affiche la réponse brute complète — sans aucun filtre — pour voir ce qui est réellement reçu.

Paramètres

Le relais est requis pour les bateaux (AISStream refuse les navigateurs). Pour les avions, il est optionnel (accès anonyme direct sinon, quota réduit). CORS : le relais n'autorise que l'origine configurée côté serveur (ALLOWED_ORIGIN) — ouvrez cette page depuis le même site que l'appli (ex. GitHub Pages) pour qu'il l'accepte.

Avions (OpenSky)

Même construction que l'appli : boîte lat/lon de ± le rayon choisi autour du point, limitée à 3,4° de côté (protection quota, jamais atteinte en usage normal).

Bateaux (AISStream)

Le relais ouvre une connexion AISStream, écoute ~10 s sur la zone, puis renvoie tout ce qui est arrivé (received = messages AIS bruts reçus, ships = navires avec position connue après filtrage). received = 0 = rien reçu du tout dans la fenêtre d'écoute (clé/zone/couverture à vérifier) ; received > 0 mais ships vide = des messages arrivent mais aucun n'a encore de position exploitable dans cette fenêtre de 10 s (fréquent en zone peu fréquentée : réessayez, ou zoomez sur une zone témoin).

Pylônes (ANFR)

ANFR a changé ses adresses le 28/09/2026 (l'ancienne répond 404). Via le relais : le relais essaie ses 5 routes connues et détaille chacune (adresse, code HTTP, nombre de lignes). En direct : cet appareil interroge lui-même data.anfr.fr, sans relais — ça dit en plus si le navigateur y a droit (CORS). Distinguer : HTTP 404 = adresse inexistante ; HTTP 200 + « refus » = adresse bonne, paramètres refusés ; « bloqué » = le navigateur n'a pas le droit (CORS) ou pas de réseau.

Monuments (Wikidata)

Utilise la position ci-dessus. Via le relais : il essaie sa requête complète puis sa variante légère et détaille chacune (code HTTP, durée, lignes) ; la 1re réponse d'une zone peut prendre 20–30 s, les suivantes sont servies par le cache (7 jours). En direct : ce téléphone interroge lui-même query.wikidata.org — dit aussi si le navigateur y a droit. Les 15 monuments les plus célèbres trouvés sont listés (classés par nombre de langues Wikipédia).

Silhouette bâtiments (IGN BD TOPO)

Télécharge la tuile (zoom 15, ~1 km) qui contient les coordonnées du haut de la page, et dit : couches présentes, nombre de bâtiments, noms des attributs (hauteur ? nombre d'étages ?) et quelques exemples. En direct dit aussi si le navigateur a le droit (CORS) : sinon l'appli passe par le relais.
