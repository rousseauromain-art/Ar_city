Débug trafic — avions & bateaux

Page à part de « villes à l'horizon » : envoie exactement les mêmes requêtes que l'appli (mêmes formules de zone), et affiche la réponse brute complète — sans aucun filtre — pour voir ce qui est réellement reçu.

Paramètres

Le relais est requis pour les bateaux (AISStream refuse les navigateurs). Pour les avions, il est optionnel (accès anonyme direct sinon, quota réduit). CORS : le relais n'autorise que l'origine configurée côté serveur (ALLOWED_ORIGIN) — ouvrez cette page depuis le même site que l'appli (ex. GitHub Pages) pour qu'il l'accepte.

Avions (OpenSky)

Même construction que l'appli : boîte lat/lon de ± le rayon choisi autour du point, limitée à 3,4° de côté (protection quota, jamais atteinte en usage normal).

Bateaux (AISStream)

Le relais ouvre une connexion AISStream, écoute ~10 s sur la zone, puis renvoie tout ce qui est arrivé (received = messages AIS bruts reçus, ships = navires avec position connue après filtrage). received = 0 = rien reçu du tout dans la fenêtre d'écoute (clé/zone/couverture à vérifier) ; received > 0 mais ships vide = des messages arrivent mais aucun n'a encore de position exploitable dans cette fenêtre de 10 s (fréquent en zone peu fréquentée : réessayez, ou zoomez sur une zone témoin).
